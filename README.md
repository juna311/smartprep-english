# EigoPath

EigoPath is a React and TypeScript English learning app for grammar lessons,
vocabulary study, personal word saving, and quiz-based review. It started as a
prototype, but the codebase is being shaped into a portfolio-ready project with
clear routes, reusable UI, typed Supabase data access, shared quiz logic, and
automated tests.

## Features

- Grammar lessons organized by level and topic.
- Vocabulary topics with beginner and intermediate word lists.
- Search across learning content.
- Supabase authentication with protected dashboard and dictionary pages.
- Personal dictionary for saved vocabulary.
- Review sessions for saved words.
- Grammar and vocabulary practice quizzes.
- Shared quiz progress and result components.
- Reusable button variants for consistent UI styling.
- Automated tests for hooks, services, routes, and key components.
